Movie Night backups

This is a personal backup tool operated by the Movie Night project owner. It is not a public Google sign-in service or the Movie Night application.

The tool is designed to encrypt database and profile-picture backups before storing them in the owner's private Google Drive folder. A hosted GitHub Actions job performs approved backup operations; an independent monitor checks whether the job reports success.

Google Drive access

The owner authorizes a dedicated desktop OAuth client using only the drive.file permission. This lets the tool manage files it creates or files explicitly opened or shared with that client. It does not request access to all files in Google Drive. The configured backup folder limits the tool's operations; the Google permission itself is scoped to the client, not exclusively to that folder.

Authorization is intended only for the owner's backup account. This information page does not collect credentials, offer a login form or start an authorization flow.
