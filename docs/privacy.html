Privacy and data handling

Movie Night backups is the project owner's personal backup tool. This page describes its intended approved operation; it is not a claim that recurring backups are currently activated.

Access and purpose

The dedicated Google OAuth client requests only drive.file. It uses that access to create and inspect the private backup folder and to upload, list and download encrypted backup generations for verification and recovery. Google Drive access is not used for advertising, profiling, sale of data or unrelated purposes.

Storage and service providers

Backup contents are encrypted with age before upload to Google Drive. The recovery identity is kept privately by the owner outside GitHub, Google Drive and the backup job; the routine job has only the public encryption recipient. Authorized recovery uses the owner's private recovery identity.

The reviewed workflow runs in the public Movie Night backup-tools repository on GitHub Actions. Its provider credentials are stored in GitHub Actions secrets, not in published source. Public output is limited to sanitized operational status and aggregate verification information. SQL dumps, personal records, object paths and credentials must not appear in public logs or artifacts.

Healthchecks.io receives limited job-status signals and sends alerts to the owner's configured email address. It does not receive the backup contents or the private recovery identity.

Retention and control

Backup generations remain in the owner's private Drive storage until the owner removes them or separately approves a retention procedure. The owner can revoke the client through their Google Account connections settings and can remove backup files in Google Drive. Revocation stops future access; it does not itself delete existing backups. No public file sharing is required.

This information site

This static GitHub Pages site contains no login form, analytics script or tracking code. GitHub provides the hosting infrastructure and may process request information under its own privacy statement.
